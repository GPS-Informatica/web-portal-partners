# Portal de partners — GPS Informática

Sitio compilado que se sirve en **https://portal.gpsinformatica.com.mx**.

Este repositorio contiene **solo el resultado de la compilación** (el `dist/` del build de Vite).
El código fuente no vive aquí.

- **Qué es:** sitio institucional de GPS Informática y portal de partners (registro, recursos,
  pedidos, oportunidades, certificados), sobre Supabase.
- **Para quién:** partners del canal de GPS Informática y visitantes del sitio.
- **Alojamiento:** GitHub Pages por rama (`main`, raíz). `404.html` es una copia de `index.html`
  porque el enrutado lo hace la aplicación en el navegador: sin esa copia, entrar directo a una
  ruta interna o recargar devolvería 404.
- **Publicado:** 2026-09-20.
